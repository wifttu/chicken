# 꼬꼬 스파이

**닭들 틈에 숨어 AI 인 척 연기하고, 진짜 플레이어를 찾아 칼로 찔러라.**
마을에는 똑같이 생긴 닭 50마리가 돌아다닌다. 대부분은 AI 고, 8마리만 플레이어(사람 또는 봇)다.
닭은 사람처럼 두 발로 서서 팔을 흔들며 걷고, 오른손에 칼을 쥐고 있다.
걸음걸이·속도·모양이 모두 같아서 겉모습으로는 구별할 수 없다. 행동으로 들키고, 행동으로 찾아낸다.

- 클라이언트: Three.js(WebGL) — 모바일 브라우저에서 바로 실행, 홈 화면에 앱으로 설치 가능(PWA), 안드로이드 APK(Capacitor)
- 서버: Node.js + `ws` — 권위 서버(30Hz 시뮬레이션, 15Hz 스냅샷)
- 빌드 단계 없음. 3D 모델·그림·소리 모두 코드로 만든다(외부 에셋 없음)

## 실행

```bash
npm install
npm start          # http://localhost:3000  (PORT 환경변수로 변경)
npm test
```

같은 와이파이의 휴대폰에서 `http://<PC IP>:3000` 으로 들어가면 된다.

메뉴에서 두 가지로 시작한다.

- **혼자 하기**: 서버 없이 브라우저 안에서 서버 로직(`server/game.js`)을 그대로 돌린다. 봇 7마리와 한 판. GitHub Pages 같은 정적 호스팅만으로 된다.
  설정에서 봇 난이도(쉬움·보통·어려움)를 고른다. AI 처럼 연기했을 때 살아남는 비율이 쉬움 69%, 보통 31%, 어려움 6% 쯤이다.
- **친구와 온라인**: WebSocket 서버에 접속해 친구들과 같은 마을에 들어간다. 사람 8명까지 한 방, 빈 자리는 봇이 채운다.
  "친구 방 만들기"를 누르면 4자리 코드가 있는 **대기실**로 가고, 친구는 그 코드로 들어온다(없는 코드면 그 자리에서 알려 준다).
  - 대기실에는 들어온 사람 목록(👑 방장)이 보이고, 방장이 **시작**을 누르면 시작한다(빈 자리는 봇).
  - 판이 끝나면 결과를 보여 준 뒤 다시 대기실로 돌아온다(방장은 "대기실로"로 바로). 방장이 나가면 다음 사람이 방장이 된다.
  - "초대 문구 복사"는 게임 주소와 방 코드를 한 번에 복사한다.
  - 서버가 잠들어 있으면 "서버 깨우는 중" 창이 뜨고(최대 1분), 취소할 수 있다.
  - 연결이 끊겨도 20초 안에 다시 붙으면 같은 닭으로 이어서 한다(그동안 닭은 제자리에 서 있다). 판 중간에 들어오면 다음 판까지 관전한다.
  - 서버(`server/hub.js`)는 코드 없이 들어오는 공개 방도 지원하지만, 화면에서는 친구 방만 쓴다.
  연결이 끊겨도 20초 안에 다시 붙으면 같은 닭으로 이어서 한다(그동안 닭은 제자리에 서 있다). 판 중간에 들어오면 다음 판까지 관전한다.
  8명이 차면 새 방이 열린다. 게임 서버가 직접 보여 주는 페이지(`npm start`, Render)에서는 바로 되고,
  그 밖의 곳(GitHub Pages)에서는 **설정 → 온라인 서버 주소**에 서버 주소를 넣거나 `client/settings.js` 의 `DEFAULT_SERVER` 를 채운다.

## 게임 규칙

| | |
|---|---|
| 한 판 | **데스매치**. 3분, 또는 플레이어가 한 명만 남을 때까지. 시작 전 3초 카운트다운 동안은 모든 닭이 멈춘다 |
| AI 닭 | 42마리로 정해져 있고, 잡히면 그대로 줄어든다(다시 태어나지 않음) |
| 플레이어를 찌름 | **+1점** |
| AI 를 찌름 | 점수는 그대로, **아무 표시도 없다**(머리 위 표시·킬 소식 없음). 찌른 사람만 알 수 있고, 칼을 2.5초 못 쓴다 |
| 찌르기 | 찌르면 **1초 동안 그 자리에 멈춰** 칼을 한 번 찌른다(움직이지도 돌지도 못함). 멈춤이 풀리면 다시 찌를 수 있다 |
| 달리기 | **플레이어(사람·봇)만**. AI 닭은 절대 뛰지 않는다 |
| 잡힘 | 다시 태어나지 않는다. 2.5초 동안 범인을 보여 준 뒤 **살아 있는 플레이어를 관전**한다(◀ ▶ 로 바꾸기, 혼자 하기는 "새 판"으로 바로 다시) |
| 승리 | 마지막까지 살아남은 닭이 1등. 시간이 다 되면 살아남은 닭끼리 잡은 수로, 잡힌 닭은 늦게 잡힐수록 위 |

- **칼**: 정면 좌우 약 57°, 몸 중심끼리 1.65m 안에서 가장 가까운 닭 하나. 찌르면 1초 동안 멈춰 칼을 한 번 쭉 내밀었다가 거둔다.
  누른 순간이 아니라 0.2초 뒤 칼끝이 가장 멀리 나간 순간에 맞는다. 그 사이에 비켜나면 빗나간다.
  헛손질이어도 똑같이 1초 멈추므로, 함부로 휘두르면 그 자리에서 들킨다.
- **AI 닭의 행동**(`server/ai.js`): 3~11m 걷고 멈춘다. 멈춰 있는 동안 땅을 쪼고(초당 55%), 두리번거리고, 가끔 퍼덕인다.
  35%는 다른 닭 곁으로 가서 무리를 짓는다. **절대 뛰지 않는다**(서버가 AI 의 달리기 입력을 막는다).
- **소동**: 닭이 잡히면 7m 안의 AI 닭은 놀라 1.6~3.2초 동안 걸어서 흩어진다. 봇도 대개 따라 걷는다. 찌른 닭이 멈춤이 풀린 뒤 섞여 빠져나갈 틈이다.
- **달리기**: 플레이어만 뛸 수 있으니, 뛰면 빨리 도망칠 수 있지만 "나는 플레이어"라고 알리는 셈이다.
- **연기 동작**: 쪼기(0.7초), 퍼덕(0.9초). 조이스틱을 살짝만 밀면 걷지 않고 제자리에서 돌아본다(AI 처럼 두리번거리기).
- **같은 움직임**: AI 와 플레이어는 같은 이동 코드(`shared/sim.js`)로 움직인다. 걷기 2.0m/s, 뛰기 4.6m/s(플레이어만), 조이스틱을 얼마나 밀든 걷는 속도는 같다.
- 잡히면 카메라가 내 닭에서 범인 쪽으로 돌아보고, 범인 발밑에 빨간 고리와 화살표가 뜬다. 그 뒤 범인부터 관전한다.
  보던 닭이 잡히면 그 닭을 잡은 닭으로 넘어간다.
- 관전할 플레이어 목록(어느 닭이 플레이어인지)은 잡힌 사람에게만 보낸다. 살아 있는 사람에게는 남은 플레이어 **수**만 보인다.

### 봇 (`server/bots.js`)

봇은 평소 AI 와 똑같이 행동하다가 수상한 닭을 골라 걷다 멈추다 하며 다가가 찌른다. 찌르고 1초 멈춘 뒤에는 놀란 AI 처럼 걸어서 빠져나간다.
봇은 뛰지 않는다(뛰면 플레이어인 게 들키니까).
봇은 누가 사람인지 거의 모른다. 화면에서 누구나 볼 수 있는 행동으로 쌓이는 **의심 점수**를 보고 고른다.

- 칼을 휘두름 +4, 뜀(AI 는 뛰지 않으니) 바로 최소 2.2에 초당 +2.5, 8초 넘게 쉬지 않고 걸음 초당 +0.5, 걸으면서 쪼기·퍼덕 +0.5
- 의심 점수는 초당 약 18%씩 줄어든다. 봇마다 감이 달라서, 노릴 닭을 고를 때 10~28% 확률로 진짜 플레이어를 알아챈다.
- 오래 아무도 못 찔렀으면 기준을 낮춰 아무나 노린다. 그래서 봇도 AI 를 잘못 찌른다.
- 시뮬레이션(16판씩, 봇 7마리와): 쉬지 않고 걷고 자주 뛰는 플레이어는 6% 만 살아남고 평균 6.8등,
  AI 처럼 연기하는 플레이어는 31% 가 살아남고 평균 4.6등. 한 판은 대개 2분 40초~3분 가고, 끝날 때 AI 는 42마리 중 31마리쯤 남는다.

## 비밀 지키기

온라인에서 다른 사람이 패킷을 들여다봐도 누가 플레이어인지 알 수 없게 했다.

- 스냅샷은 닭마다 `[id, x, z, 방향, 동작]` 다섯 숫자뿐이다. AI 와 플레이어가 같은 꼴이다.
- id 는 무작위이고 id 순으로 보내므로 만든 순서도 드러나지 않는다. 처음 닭을 놓을 때도 AI 와 플레이어 순서를 섞는다.
- 나 말고 다른 닭의 쿨다운·의심 점수·이름은 보내지 않는다. AI 를 찔렀다는 것도 찌른 사람에게만 알린다.

## 구조

```
shared/   config.js(수치) map.js(맵·충돌) sim.js(이동, 서버·클라이언트 공용) rng.js
server/   game.js(한 판의 권위 시뮬레이션) ai.js(AI 닭) bots.js(봇) hub.js(온라인 방) index.js(HTTP + WebSocket)
client/   main.js(화면·예측·보간·HUD) chickens.js(사람형 닭: InstancedMesh 6개) world.js(마을) fx.js(연기·깃털·표시)
          input.js audio.js net.js local.js(혼자 하기) index.html style.css
test/     game.test.js
android/  Capacitor 안드로이드 프로젝트 (MainActivity: 전체 화면·화면 켜짐 유지, 가로 고정, 아이콘·시작 화면)
```

- 내 닭은 입력을 보내자마자 같은 `stepChicken` 으로 미리 움직이고(예측), 서버가 확인한 입력 번호(`ack`) 뒤의 입력만 다시 돌려 맞춘다.
  서버는 사람의 닭을 받은 입력 하나에 꼭 한 번만 움직인다(입력이 비면 기다리고, 밀려 쌓이면 한 틱에 두 개씩 따라잡는다).
  찌르기 멈춤도 입력 수로 세므로 예측과 서버가 한 치도 어긋나지 않는다.
- 내 닭은 30Hz 틱 사이를 프레임마다 이어 그린다. 그래서 60·90·120Hz 화면에서 뛰어도 끊기지 않는다.
- 다른 닭은 120ms 늦게, 서버 틱 번호를 기준으로 두 스냅샷 사이를 이어 그린다.
- 닭 50마리를 부위별 InstancedMesh(몸통+머리·팔·허벅지·정강이+발·칼·그림자)로 그려 드로우콜이 6번이다.
  뼈대는 뿌리 → 엉덩이 → 몸통 → 어깨 → 팔 → 손 → 칼, 엉덩이 → 허벅지 → 무릎 → 정강이 순서로 행렬을 곱해 만든다. 마을은 꼭짓점 색을 입힌 메시 몇 개로 합쳤고,
  건물 그림자는 처음에 한 번만 그린다.

## 휴대폰으로 하기

### 안드로이드 앱 (APK)

APK 는 원할 때만 만든다: GitHub → **Actions → Android APK → Run workflow**. `.github/workflows/android.yml` 이 테스트 → `npm run build:pages` → `npx cap sync android` → Gradle 로 APK 를 만든다.
평소에는 GitHub Pages 주소(`https://wifttu.github.io/chicken/`)로 하면 올릴 때마다 바로 새 버전이 뜬다.

- 기본 브랜치에서 만든 APK 는 **android-latest** 릴리스에 올라간다. 휴대폰에서 이 주소를 열어 받으면 된다:
  `https://github.com/wifttu/chicken/releases/download/android-latest/kkokko-spy.apk`
- 다른 브랜치의 APK 는 Actions 실행 화면의 Artifacts(`kkokko-spy-apk`)에서 받는다.
- 처음 설치할 때 "출처를 알 수 없는 앱 설치"를 허용해야 한다. 플레이 스토어 앱이 아니라서 Play 프로텍트가 한 번 물어볼 수 있다.
- 앱은 가로 화면 전체(상태 표시줄·내비게이션 바 숨김)로 열리고, 하는 동안 화면이 꺼지지 않는다. 뒤로 가기는 열린 창 닫기 → 게임 나가기 확인 → 앱 끄기 순서.
- 서명은 저장소에 둔 공개 디버그 키(`android/app/debug.keystore`, 비밀번호 `android`)라서 새 APK 가 이전 것 위에 덮어 설치된다.
  플레이 스토어에 올리려면 따로 만든 비공개 키로 release 빌드를 서명해야 한다.
- 앱 안에서 온라인을 하려면 `client/settings.js` 의 `DEFAULT_SERVER` 에 Render 서버 주소를 넣거나 게임 설정에 붙여 넣는다.

직접 빌드하려면 Android Studio(또는 Android SDK)와 JDK 21 이 필요하다.

```bash
npm run android                 # dist 를 만들고 android 프로젝트에 복사
cd android && ./gradlew assembleDebug   # android/app/build/outputs/apk/debug/app-debug.apk
```

### 아이폰 · 브라우저

Safari 공유 버튼 → **홈 화면에 추가**, 안드로이드 Chrome 은 메뉴 → **앱 설치**. 메뉴의 "📱 앱으로 설치" 버튼이 안내한다.

### 휴대폰에 맞춘 것

- **왼손잡이 배치**: 설정에서 켜면 조이스틱이 오른쪽, 행동 버튼이 왼쪽으로 간다.
- **내 기록**: 판 수, 우승, 생존율, 잡은 플레이어, 한 판 최다를 이 기기(브라우저)에 저장해 메뉴의 "내 기록"에서 보여 준다.
- **가로 화면 전용**. 앱은 가로로 고정되고, 브라우저에서 휴대폰을 세로로 들면 "가로로 돌려 주세요" 안내가 화면을 덮는다.
- 왼쪽 아래에 흐린 조이스틱이 늘 보이고, 화면 왼쪽 어디를 눌러도 그 자리에서 조이스틱이 시작된다.
- 해상도는 최대 1.75배에서 시작해 프레임이 40 아래로 떨어지면 스스로 낮추고(최저 0.55배), 넉넉해지면 되돌린다. 그림자 지도는 1024.
- 게임 중에는 화면 꺼짐 방지(Wake Lock), 전체 화면·가로 고정을 시도한다. 찌르기·잡힘에 진동.

## 배포

### GitHub Pages (혼자 하기)

기본 브랜치에 푸시할 때마다 `.github/workflows/pages.yml` 이 테스트 후 `npm run build:pages` 로 `dist/` 를 만들어 배포한다.
저장소 **Settings → Pages → Source 를 "GitHub Actions"** 로 한 번만 바꿔 두면 된다. 주소는 `https://wifttu.github.io/chicken/`.
휴대폰에서는 이 주소를 열어 바로 하면 되고, 고칠 때마다 1~2분 뒤 새로고침하면 새 버전이 뜬다(서비스 워커가 매번 서버에 새 파일이 있는지 확인한다).

### Render (온라인 서버)

1. Render 에서 **New → Blueprint** 로 이 저장소를 연결하면 `render.yaml` 설정(무료, 싱가포르)이 그대로 뜬다. **Apply**.
2. `https://kkokko-spy-xxxx.onrender.com` 같은 주소가 생긴다. 그 주소를 열면 서버가 보여 주는 같은 게임이 뜨고, 온라인이 바로 된다.
3. GitHub Pages 쪽에서도 온라인을 쓰려면 그 주소를 `client/settings.js` 의 `DEFAULT_SERVER` 에 넣거나, 게임의 설정에 붙여 넣는다.

무료 플랜은 15분간 접속이 없으면 잠들고, 깨어나는 데 최대 1분 걸린다(클라이언트가 자동으로 다시 시도한다).
